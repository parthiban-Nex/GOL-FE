A production-ready React admin dashboard scaffold built with **Vite**, **React Router**,**Tailwind CSS v4**, and **Axios**.
## Quick start

```bash
npm install
npm run dev
```

Then open the URL Vite prints (defaults to `http://localhost:5173`)
